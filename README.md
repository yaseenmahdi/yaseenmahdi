## Featured Projects

### [Commerce Integration Core](https://github.com/yaseenmahdi/commerce-integration-core)

A TypeScript backend that brings supplier data and commerce events into a consistent system. It covers API adapters, product and inventory rules, PostgreSQL persistence, signed webhooks, retries, and duplicate-event handling.

**Tech:** TypeScript · Node.js · Express · PostgreSQL · Docker · REST APIs

**Also exploring:** [AWS serverless webhook extension](https://github.com/yaseenmahdi/commerce-integration-core/pull/1) with local/CI testing. **Not a live AWS deployment.**

### [Service Operations Platform](https://github.com/yaseenmahdi/service-operations-platform)

A Java/Spring Boot backend for managing service sites, work orders, technicians, schedules, and inventory. Built around transactional workflows, data validation, optimistic locking, and automated tests.

**Tech:** Java · Spring Boot · PostgreSQL · JPA · Flyway · Docker · OpenAPI

### [Global Expedition Journal](https://github.com/yaseenmahdi/global-expedition-journal)

A full-stack educational app I built during my UBR innovation fellowship. Students can explore 195 countries, complete activities, keep journals, track their progress, and use digital passports; teachers have their own workflows.

**Tech:** React · TypeScript · Supabase/PostgreSQL · Tailwind CSS

🌍 **[Try the public demo](https://globe-explorer-passport.lovable.app/)** · [Case study](https://github.com/yaseenmahdi/global-expedition-journal/blob/main/docs/CASE-STUDY.md)

### [AI Video Production Pipeline](https://github.com/yaseenmahdi/ai-video-production-pipeline)

A Python workflow project that connects research, scripting, media generation, and video rendering. I focused on making the stages configurable, testable, and able to resume after failures.

**Tech:** Python · LangGraph · Pydantic · Remotion · React/TypeScript

### [Automation Systems Blueprints](https://github.com/yaseenmahdi/automation-systems-blueprints)

System-design reference projects for lead intake, CRM synchronization, and follow-up workflows. They document validation, deduplication, event handling, and error recovery. **Design blueprints, not production client deployments.**

**Focus:** APIs · Webhooks · CRM workflows · Reliability · Documentation
